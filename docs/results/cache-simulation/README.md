# 两路 I/D Cache 功能与性能仿真

2026-10-28，Verilator，CPU 执行同一份 `cache_smoke.hex`，分别 CACHE_ENABLE=1 / 0；SET_BITS=8，每侧 16 KiB、两路、32 字节行。MULH_PIPELINE=1、LOAD_WORD_ONLY=0，与板级修订一致。DDR 外部模型固定为同一个确定性背压/可变延迟模型，不包括加密 PHY。

| 指标 | 无缓存 | 缓存开启 |
| --- | ---: | ---: |
| 100 次已热身的 DDR 函数调用计时 | 21325 周期 | 4336 周期 |
| 整个自检程序周期 | 166067 | 96006 |
| 外部 DDR 事务 | 10570 | 1232 |

热身函数循环加速 4.9181 倍；整体 1.7298 倍；外部事务减少 88.3444%。缓存版本还执行了维护寄存器和统计计数器检查，无缓存版本跳过不存在的寄存器。计时循环相同，额外检查在计时区间之外。

缓存运行统计：I 行命中 516、D 行命中 7933、成功写回 561、指令行缓冲命中 1486。统计为本程序整体计数，不是普适命中率。

模块检查覆盖两路并存、LRU 脏行替换、随机字节掩码、响应背压、填充/写回错误、维护失败后故障保持、维护后指令一致性，397 次外部读、220 次写，7,788 周期通过。CPU 执行 16 KiB DDR 数据自检、跨行指令，并运行/修改已经热身的 DDR 函数；另连续 16 次修改最近的指令缓冲行，FENCE.I 后均返回新结果，维护 MMIO 检查通过。端口仲裁允许未消费的取指响应与数据事务并存，解决满前端队列与 store 形成的死锁。

本目录现为面积优化后的同步元数据版本。复位逐组初始化，同一 D 读地址服务普通访问和维护扫描；元数据优化本身未增加访存周期，原固件的前后对照见 [cache-area](../cache-area/README.md)。本页记录新增乘法检查后，同一份固件的缓存开启/关闭对照。

当前固件另加入 4 组 MULH/MULHSU/MULHU 边界值（共 12 次高位乘法），在热代码计时之外执行，缓存/无缓存均打印 CPU MULH PASS。其用途是实板直接覆盖本轮 DSP 流水数据寄存器连续采样改动。CPU 的每周期吞吐未变；新增检查会增加整个自检耗时，固件布局也会影响少量预测开销，因此当前完整测试数字与 cache-area 中旧固件记录分开保存。当前 CPU 还在入队时登记配对关系和顺序预测标志，保持原压缩队列拓扑。

最新版本同时覆盖 3 组 MIN/MAX/MINU/MAXU 边界值（共 12 次）及每次结果后的立即 RAW 依赖。MIN/MAX 在已有 MEM 级计算，紧邻依赖等待 WB 一拍；CoreMark 没有这些操作，测量周期保持 1,983,373。取指提示改为轻量辅助通道合法指令白名单，完整 ID/EX 译码仍负责异常；预测顺序标志在宽 PC 选择前计算。MULH_PIPELINE=0/1 各 219 轮差分均通过。当前缓存写命中在原有响应保持拍提交到数据 RAM，不增加 CPU 等待；替换选择仅使用 Valid/LRU，避免引入命中 Tag 比较。

这些是特定工作负载的 RTL 仿真结果，不是 CoreMark、不代表实板吞吐或当前时序闭合。原始记录为 unit.log、cached.log、uncached.log；固件、源码快照和哈希一同保存。复现：`make cache-test`。此次 CPU 分支重定向和 TCM 读使能修改的差分/异常/中断及 CoreMark 日志也一同归档，短 CoreMark 为 1,983,373 测量周期，5.041916 等效 CoreMark/MHz；该短测不满足正式成绩的 10 秒要求。
