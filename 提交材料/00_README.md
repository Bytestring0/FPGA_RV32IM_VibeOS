# 提交材料

这个目录按赛题条目整理，评委想看哪块可以直接翻对应文件夹。

## 结果先说

CoreMark 跑的是 10000 次迭代，19.45 秒，514.085 分，折合 5.040 CoreMark/MHz，CRC 全部通过。位流在 102 MHz 下时序全满足，综合用了 46,747 个 LUT（70.19%），折算下来 CoreMark/LUT 是 0.0110。

端侧大模型是完整的 24 层、上下文 2048、词表 248,320，没有换小模型。实测首字 11.1 秒，之后每个 token 2.03 秒，约 0.49 token/s。

## 烧录前注意两件事

PDS 不认中文路径，烧位流要用 `D:\FPGA\RiscV\bitstream\ag_npu_board_top.sbit`，本目录里的副本只是归档。另外串口和下载器都只能被一个程序占用，烧之前把别的串口工具关掉。

正确顺序是反过来利用“烧位流会复位”这一点：先让上传脚本开始监听 COM12，再烧位流，板子复位后重新发 ASSET_READY，脚本正好接住。命令在 `08_位流与镜像/README.md`。

## 没做完的部分

突发传输的 RTL 写了也仿真过了，但带突发的位流在模型装载这种密集 DDR 流量下会挂死，所以提交的位流是单拍读。ILA 波形是在 96 MHz 的分析位流上抓的，CPU 域满足，剩两条 −0.039 ns 在厂商 DDR PHY 内部，CoreMark 不碰 DDR，波形本身有效。识别率还没测，演示视频还没录。
