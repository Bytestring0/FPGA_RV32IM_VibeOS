# 基于紫光同创 FPGA 的 RISC-V + 端侧 AI 加速系统 设计报告

> 本文所有性能数字均来自实板串口输出或 PDS 2025.2 报告文件；未完成项在文中明确标注，不做推测性陈述。

## 1. 系统概述

本设计在紫光同创 PG2L100H-6FBG676 开发板上实现了一颗自研 RV32IM 处理器、一套端侧大模型推理加速单元，以及 HDMI 文本界面和键盘/UART 交互的端侧 Agent。

链路为：SD 卡 → DDR → NPU/CPU → HDMI。固件在 TCM 中启动，通过 UART 资源通道载入 DDR 端应用镜像，再从 SD 卡装载模型权重运行。

## 2. CPU 微架构

- ISA：RV32I 基础整数指令集，另实现 M 扩展与 Zba/Zbb 子集（sh1add/sh2add/sh3add、clz/ctz/cpop、min/max、rev8 等），非法编码触发异常。
- 流水线：取指-译码-执行-访存-写回五级，支持双发射（x/m 两条通道），前递与停顿由 hazard 单元处理。
- 分支预测：BTB + 返回地址栈，训练信息随执行级回写；预测失败冲刷前端并从正确 PC 重取。
- 异常/中断：完整 CSR 组、ecall/ebreak/mret、定时器中断；trap 入口记录 mcause/mepc/mtval 并可上报串口。
- CoreMark 表现：5.040 CoreMark/MHz，说明双发射与预测在整数负载上生效。

## 3. 存储系统

- TCM：64 KiB 双端口片上存储，存放启动代码与热点函数；CoreMark 基准整体在 TCM 内执行，测量期间不跑 UI。
- Cache：指令/数据各一套 2 路组相联 Cache，行宽 256 bit，含写回与维护（fence.i）通路。
- DDR 通路：自研异步桥接 + 厂商 DDR PHY，最多 32 个 outstanding 请求，保证跨时钟域顺序性。
- 突发传输：桥内实现相邻读请求合并为真正的 AXI INCR 突发（ag_hmic_read_burst），RTL 仿真通过；但带突发的位流在实板重载下挂死，未通过验收，当前提交位流使用单拍读。这是本设计最主要的未完成项。

## 4. AI 加速单元

- 数据格式：权重 W4（分组 128，带 scale/zero），激活 A8，累加与归一化走 Q16 定点，四舍五入 RNE，带饱和与下溢处理。
- 并行度：64 条 MAC lane + 8 条 Delta lane，单次张量作业由 CPU 通过寄存器接口下发，DMA 直接读写 DDR。
- 模型规模：24 层、上下文 2048、词表 248,320，完整模型与完整词表，未替换为小模型。
- 模型资源：HEADW4.BIN 388 MB（W4 权重）、CPU_RAW.BIN 510 MB（其中 508.5 MB 是 tied 输入嵌入，fp16）、词表 13.3 MB、张量目录 0.74 MB。

## 5. 端侧 Agent 与交互

- 界面：MS7210 HDMI 输出 720x480p，80x30 字符单元，全英文 UI。
- 输入：板载 KEY1–KEY4（低有效）、屏幕虚拟键盘、UART 键盘。
- 功能：任务菜单、工具调用（计算/查询/计时）、工具回执、CoreMark 现场跑分页、模型装载进度条、直连对话模式。
- Agent 协议：模型输出 tool_call/function/parameter 结构化调用，板端解析后执行真实工具并把回执喂回模型。

## 7. 已知限制（如实列出）

1. 突发传输版位流未通过实板验收：时序已闭合（+0.296 ns），但在模型装载的密集 DDR 流量下挂死，已回退到单拍读位流。
2. ILA 波形尚未取得 2025.2 证据：插核与探针已通过（CPU 时序 +0.37 ns），但厂商 DDR PHY 内部路径仍有 -0.01～-0.03 ns 违例，尚无可提交波形。
3. 识别率/任务成功率未量化：没有任何可提交的测量数据。
4. 直连对话模式：已实现并实测，**已定位此前"不吐字"的原因**。一次成功运行（rc=0）为 19 token / 76 字节，即每 token 约 4 字节，说明模型输出的是**中文**，而 HDMI 字库仅包含 ASCII 128 字模，中文码点被映射为占位符，故屏幕无显示。已在直连对话提示词前加入一行英文系统提示（约 15 token）规避，当前板上固件即该版本。实测 TTFT **11.1 s**、解码 **2.03 s/token（0.492 tok/s）**、端到端 0.380 tok/s；惰性嵌入版为 3.00 s/token（随机 2 KB 读会重走 FAT 链）。
5. 模型标注 quality_approved=0，在完成识别率测量前不声称与 BF16 等价。
6. 64 KiB TCM 已接近用满（余量不足 1 KiB）。尝试在屏幕上追加 TTFT/tok-s 指标行会触发链接断言 `Agent TCM overflow`，故该功能未加入固件，指标经串口输出。若需上屏，需先把部分冷代码移出 TCM。

## 8. 复现步骤

1. PDS 2025.2 打开 npu_system_pds/npu_hot102_20261104，位流位于 prj_tasks/pnr_1/generate_bitstream/ag_npu_board_top.sbit。
2. 固件构建：python3 AI加速器/npu/system/tools/build_agent_interactive.py --output <dir> --config <model>。
3. 上板：board_agent_uart.ps1 通过 JTAG 烧位流，再经 UART 资源通道载入 APPRES/FONT 与固件镜像。
4. CoreMark：主菜单选择 CoreMark 并按两次确认，结果同时输出到 HDMI 与串口。
